小火箭节点

小火箭节点是面向机场订阅与网络加速的说明页，帮助你按设备选择客户端、按流量选择套餐，并了解从订阅到连接的基本步骤。

品牌简介

小火箭节点把可用线路按套餐整理为订阅，供已安装的代理客户端读取。页面重点不是堆砌线路名称，而是说明三件事：每月流量、可同时在线的设备数，以及适合哪类客户端。

基础版适合个人轻度浏览，旗舰版在流量、设备数和线路类型上更完整，团队版面向多人共用。连接质量会受本地网络、时段和所选节点影响，本页不承诺固定延迟或速率。

客户端本身请从对应应用的正规发布渠道获取。本页链接只指向站内说明，不提供安装包。

客户端选择

按设备从上到下确认，再决定订阅套餐。不同客户端界面名称可能不同，但导入订阅、更新节点、选择节点、开启代理这四步是共通的。

  1. 1手机优先确认系统

    iPhone 与 iPad 通常使用支持订阅链接的规则客户端；Android 则选择能导入订阅并手动更新节点的客户端。先确认系统版本能安装该应用，再购买流量。

  2. 2电脑选择图形客户端

    Windows 与 macOS 更适合带订阅管理的图形客户端。若只需浏览器访问，可先用系统代理；若要让更多软件走代理，再在客户端里打开相应的系统代理开关。

  3. 3按套餐匹配设备数

    基础版同时在线 3 台，旗舰版 5 台，团队版 20 台。超出额度时，后接入的设备可能无法更新订阅，应先退出不使用的设备。

  4. 4核对线路需求

    只做网页与即时通讯，基础线路即可。需要更稳定的流媒体或游戏优化时，再看旗舰版中的全节点流媒体解锁与 IPLC 专线说明，而不是盲目买最大流量。

使用场景

日常浏览与办公

查阅资料、收发邮件和同步云盘时，优先选负载较低的节点，并避免多台设备同时做大文件传输，以便把每月流量用在持续访问上。

视频与流媒体

播放前先更新订阅，换到套餐包含的流媒体线路。若片源仍提示地区限制，更换同类型节点后再试，不要连续切换过多节点。

多人与小团队

团队版适合需要集中管理设备名额的小组。共用前约定谁负责更新订阅、如何登记设备，避免个人设备长期占用名额。

操作说明

  1. 1在上方确认流量、同时在线设备和线路类型，年付价格按所列金额理解，不另设隐藏档位。
  2. 2完成账户开通后，在订阅页复制订阅链接。请只在自己的客户端中使用，不要公开到论坛或群聊。
  3. 3打开已安装客户端，找到订阅或配置入口，粘贴链接并更新。若客户端区分“节点”和“策略组”，先更新节点再选择策略。
  4. 4选一个当前可用节点并开启代理。需要全局或按规则分流时，以客户端自带说明为准。
  5. 5用普通网页检查是否已通过所选节点访问。结束后可关闭系统代理，避免本地软件继续占用流量。

常见问题

小火箭节点和客户端是什么关系？

小火箭节点提供按套餐发放的订阅与线路说明；客户端负责在你的手机或电脑上导入订阅并建立连接。两者需要配合使用，单独打开网页并不会自动加速网络。

应该买哪一档？

一人、设备不超过 3 台且流量需求有限，选基础版。需要更多流量、5 台设备、流媒体与专线优化时看旗舰版。大约 20 台设备共同使用时再评估团队版。

客户端从哪里下载更稳妥？

从该客户端的正规应用商店或开发者公布的发布页获取，并核对应用名称与开发者。本页不托管安装包，站内按钮只跳到操作说明。

更新订阅后看不到节点怎么办？

先检查链接是否完整、是否过期，再在客户端手动更新一次。仍为空时，确认当前套餐仍有剩余流量，且登录设备没有超过同时在线数量。

流量如何计算？

三个套餐的月流量分别为 100GB、300GB 和 1000GB。上传与下载通常都计入用量，具体以订阅账户显示为准。大文件和长时间视频会更快用完当月额度。

年付和月付如何选择？

月付分别是 ¥15、¥35、¥85。按年支付的标价是 ¥150、¥350、¥850。若只试用一个月，先用月付；确定长期使用再比较年付金额。
